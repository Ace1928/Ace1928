# Hey, I'm Lloyd

I'm building [NeuroForge](https://neuroforge.io/) and open-source tools for working with language, knowledge and AI.

A few things I'm working on:

- **[word_forge](https://github.com/Ace1928/word_forge)** — Word relationships, semantic graphs and lexical search.
- **[glyph_forge](https://github.com/Ace1928/glyph_forge)** — Turn images, text and video into character art, from the terminal or [browser studio](https://ace1928.github.io/glyph_forge/).
- **[RKC](https://github.com/neuroforge-io/RKC)** — Turn folders, repos and docs into searchable knowledge, with citations back to the source. Local GUI, CLI and MCP.
- **[minecraft_ai](https://github.com/Ace1928/minecraft_ai)** — Early-stage work towards an agent that plays Minecraft through vision and keyboard/mouse controls, with planning and memory.

I'm also testing [NeuroForge Handbook on Poe](https://poe.com/NeuroForgeHandbook): an experimental English keyword lookup for handbook passages. Uses Poe points.

If any of this looks useful, give it a go. Feedback, bug reports and contributions are very welcome.
